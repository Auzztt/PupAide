# PupAide
An all-in-one office assistant toolbox, integrating multiple functions such as batch processing of PDFs, batch replacement and generation of Word/Excel files, and OCR text recognition, designed for learning and personal use.

# PupAide
一个集成了多种功能的办公助手工具箱，包括批量处理PDF、批量替换和生成Word/Excel文件、OCR文字识别等功能，适用于学习和个人使用。
